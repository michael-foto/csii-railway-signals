# Asset drop

Put the exported signal assets here. Everything in this folder is copied into the mod's deploy
directory by the build, and the game picks prefabs up from anywhere under its user data folder,
so no registration code is needed: name the assets in the mod's settings and they are used.

Each exported asset is a set of files sharing one name: `.Prefab`, `.Geometry`, `.Surface`,
`.Texture`. Copy all of them.

See the "Making the signal assets" section of the top level README for what to model.
